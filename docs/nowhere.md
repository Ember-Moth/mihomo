# Nowhere outbound (NW3)

This fork implements the Vector client of [Nowhere 3.3.0](https://github.com/NodePassProject/Nowhere/releases/tag/v3.3.0), wire version **NW3**, in Go. It supports TLS and QUIC carriers, TCP and UDP forwarding, Morph, and the authenticated Morph Prelude extension. It is included in ordinary builds and requires no native library or extra build tag.

```yaml
proxies:
  - name: nowhere
    type: nowhere
    server: portal.example.com
    port: 2000
    password: "0123456789abcdef0123456789abcdef" # replace with your shared key
    network: tcp # tcp = TLS; udp = QUIC
    morph: true # default; must match Portal
    udp: true # default; enable forwarding UDP payloads on either carrier
    # sni: portal.example.com
    # pin: "<64 lowercase hex characters: SHA-256 of the leaf certificate>"
    # tcp-prelude: fade # fade (default), full8, low7
    # udp-prelude: fade # fade (default), full8, low7
    # handshake-timeout: 10000 # milliseconds; 0 uses the default
    # setup-timeout: 20000 # milliseconds; includes transport and Flow setup
    # dialer-proxy: another-outbound
    # interface-name: eth0
    # routing-mark: 1234
    # ip-version: ipv4
```

The shared key is exactly 32 lowercase hexadecimal **text characters**, used as ASCII without hex decoding. It is the value generated by `nowhere generate-key`; the example above is only a placeholder.

`network` selects the connection to Portal, independently of the payload protocol. TLS uses one connection per Flow and length-prefixed UDP packets. QUIC shares one authenticated connection, uses streams for TCP, and control streams plus DATAGRAMs for UDP. A mihomo UDP association can contact multiple targets; the adapter creates a separate Nowhere Flow for each target.

Both carriers require TLS 1.3 and ALPN `nw3`, with 0-RTT disabled. A connection waits for READY before sending target payload. There is no automatic carrier fallback, including when a QUIC peer lacks DATAGRAM support. Existing Flows end on connection loss; later dials establish a new connection.

## Certificate trust

Without `pin`, the client verifies the hostname and mihomo's configured CA trust pool. `sni` overrides the certificate hostname while `server` remains the actual endpoint. For self-signed Portal certificates, obtain the fingerprint through a trusted channel and supply `pin`. It matches the exact leaf certificate, replacing CA/hostname validation. TLS still verifies the peer's possession of the certificate key.

`skip-cert-verify`, `client-fingerprint`, and custom `alpn` are rejected. Morph masks the wire below TLS/QUIC; it does not replace certificate authentication. Morph TCP includes the required authenticated Prelude, with a fresh per-client identity and shared monotonic counter. Prelude generation policies do not need to match Portal's policy.

QUIC Morph wraps each UDP datagram separately. It uses 1200-byte QUIC transport packets plus the 12-byte Morph nonce, with path MTU discovery disabled for this carrier. This avoids bypassing masking through GSO/raw socket optimizations. Business UDP payloads are independently fragmented and reassembled; transport packet size does not cap business packets at 1200 bytes.

## Share links

```text
nowhere://0123456789abcdef0123456789abcdef@portal.example.com:2000?net=udp&morph=1#My%20Portal
```

The subscription converter recognizes `nowhere://`, including IPv6 hosts and percent-encoded names/keys. `net` defaults to `tcp`; `morph` defaults to `1`. Optional `sni` and `pin` are preserved. Known duplicate parameters use the first value; malformed values are rejected. Carrier paths and password-style `user:password` userinfo are unsupported.

## Implementation and limits

`pkg/nowhere` owns the protocol, injected transport callbacks, connection reuse, Morph and bounded UDP state. `adapter/outbound/nowhere*.go` owns mihomo configuration and multi-target UDP adaptation. It uses the repository's existing `metacubex/tls`, `metacubex/quic-go`, and Go crypto dependencies, with the root `go.mod`.

The client admits at most 1024 simultaneous/pending Flows; each mihomo UDP association admits at most 256 targets. QUIC receive queues and reassembly share a 4 MiB payload budget, with 64 partial packets, 10-second reassembly expiry and 64 queued packets per Flow. The adapter's reply queues share another 4 MiB budget across all of the node's UDP associations. Slow receive queues drop packets rather than blocking other Flows. UDP target Flows expire after inactivity. Configuration replacement closes the client's connections, pending operations and UDP associations.

The scope is Vector outbound. A Rust Portal may forward through a remote Egress transparently; mihomo does not implement Portal listeners or Egress registration. Nowhere v1.x (`now/1`, paired uplink/downlink, TLS Mux) is not wire-compatible.

Some UoT and fragment-reassembly code is adapted from Polaris's Go port of Nowhere v1.8; those files retain their original copyright/SPDX notices. NW3 framing, authentication and Morph follow the current [Core specification](https://github.com/NodePassProject/Nowhere-Protocol/blob/main/PROTOCOL.md) and [Prelude extension](https://github.com/NodePassProject/Nowhere/blob/v3.3.0/docs/prelude.md).

## Verification

```sh
go test -race ./pkg/nowhere/...
go test -race ./adapter ./common/convert -run Nowhere
NOWHERE_TEST_BINARY=/absolute/path/to/nowhere \
  go test -race ./pkg/nowhere/... ./adapter/outbound -run 'RustPortalInterop|Nowhere|Morph' -count=1 -timeout=3m
```

Real interoperability tests require the pinned Rust v3.3.0 binary; without it they report a skip. They create temporary certificates and local TCP/UDP echo targets, require no external credentials, and terminate their Portal processes. The dedicated `Nowhere` workflow verifies release archive SHA-256 values and runs these tests on Linux, macOS and Windows for `Alpha` pushes and pull requests.

Darwin's default `net.inet.udp.maxdgram=9216` limits the real target socket: its live echo cases use up to 8192 bytes, while Linux/Windows use 60000 bytes. Codec/reassembly tests cover the protocol's 65535-byte bound independently of target sockets.
